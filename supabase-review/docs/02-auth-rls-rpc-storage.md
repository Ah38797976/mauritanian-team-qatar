# 02 — المصادقة، RLS، RPC، Storage (الإنفاذ على الخادم)

## 1) المصادقة (Supabase Auth)
- مشروع **بدعوة فقط**: تعطيل التسجيل العام (Sign-ups) من الإعدادات؛ الحسابات يُنشئها المؤسس عبر **Edge Function** تستخدم المفتاح السري **من أسرار الدالة فقط** (لا يصل لأي ملف في الواجهة ولا للمستودع).
- طريقة الدخول: بريد + كلمة مرور قوية، أو رابط سحري؛ **MFA إلزامي للمؤسس والإدارة**. حدّ لمحاولات الدخول وتأكيد البريد مفعّلان.
- **الدور يُقرأ من `team_members` فقط** — لا من `user_metadata` ولا من أي claim يستطيع المستخدم تعديله.
- الفريق يُشتق من الجلسة (`app.my_team()`)؛ الواجهة لا ترسل `team_id` ولا الدور ولا هوية المنفِّذ.
- يُحذف مبدّل المستخدم التجريبي (`Store.setUser`) من أي نسخة متصلة بقاعدة بيانات.

## 2) نموذج الإنفاذ
| الطبقة | القاعدة |
|---|---|
| القراءة | سياسات RLS من نوع SELECT، أو RPC مقيّدة بالنطاق (`rpc_get_roster`, `rpc_get_stat_rows`) حيث يلزم إخفاء أعمدة |
| الكتابة | **لا سياسات كتابة ولا صلاحيات INSERT/UPDATE/DELETE** على الجداول؛ كل التعديل داخل دوال RPC (`SECURITY DEFINER`, `search_path=''`) |
| anon | لا شيء إطلاقًا؛ الدوال ممنوحة لـ `authenticated` فقط |
| الدوال المساعدة | في مخطط `app` غير معروض في Data API |
| عقد الأخطاء | كما في `Store`: نص فارغ = نجاح، وإلا رسالة عربية دون أي تغيير |

## 4) Storage (الصور)
- حاوية **خاصة** `player-photos`، حد 2MB، أنواع jpg/png/webp، مسار ثابت `team/player/photo.ext`.
- سياسات `storage.objects`: القراءة لمن يملك `viewPlayers`، الرفع والحذف لمن يملك `players` داخل مجلد فريقه فقط؛ **لا UPDATE** (الملفات غير قابلة للاستبدال).
- العرض بروابط موقّعة قصيرة العمر (≈5 دقائق). تجريد بيانات EXIF قبل الرفع في الواجهة. التحقق من النوع الحقيقي للملف خادميًا عبر `allowed_mime_types`.
- حذف لاعب لا يحذف ملفاته تلقائيًا: يُحذف الكائن عبر Storage API، ويلزم تنظيف دوري للأيتام (انظر المخاطر).

## 5) المفاتيح والواجهة
- في الواجهة: **المفتاح العام فقط** (anon/publishable) — محمي بـ RLS. المحوّل يرفض أي مفتاح سري.
- لا مفاتيح في المستودع؛ أسرار Edge Functions في إعدادات Supabase. إدارة الإصدارات: سكربت supabase-js من CDN مثبّت بإصدار محدد وقديم ≥ أسبوعين، مع CSP صارمة.
- تدوير المفاتيح عند أي تسريب مشتبه، ومراجعة سجل الدخول دوريًا.
