# فريق الجالية الموريتانية في قطر — موقع + لوحة إدارة (نموذج أولي)

- `/` الموقع العام (للزوّار) — `index.html` + `site/` + `data/public.json`
- `/admin/` لوحة الإدارة (منفصلة تمامًا) — `admin/`
- بيانات وهمية فقط، بلا اتصال بأي خدمة خارجية. الصلاحيات في الواجهة محاكاة وليست حماية (انظر التعليق في رأس `admin/js/store.js`: «ليست حماية إنتاجية»؛ الحماية الفعلية مسؤولية الخادم عند ربط Supabase).

## النشر على Vercel
استورد المستودع كمشروع Static: Framework = Other، بلا Build Command، Output Directory = `.` (الجذر). ملف `vercel.json` يضبط الرؤوس وإعادة التوجيه.

## تشغيل محلي
```bash
python3 -m http.server 8080 --bind 127.0.0.1
# الموقع: http://127.0.0.1:8080/    اللوحة: http://127.0.0.1:8080/admin/
```
تعديلات اللوحة تظهر في الموقع في المتصفح نفسه فقط حتى يُربط Supabase.
